# Public assets

Drop two files here to complete the site:

- **`profile.jpg`** — your headshot (square works best, e.g. 800×800). Until it's
  added, the hero shows a navy "MM" monogram fallback automatically.
- **`resume.pdf`** — your resume. The "Download Resume" buttons link to `/resume.pdf`.

No code changes needed — the paths are already wired in `lib/data.ts`.
